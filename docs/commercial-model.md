# Commercial model and unit economics

The OSS distribution loop is adapter contribution → reproducible scorecard → vendor remediation → improved score → procurement use. The benchmark must remain useful without a commercial account.

## Buyers and urgent decisions

| Buyer | Decision | Recurrence |
|---|---|---|
| AI platform lead | Which runtime can host autonomous engineering? | Every runtime/model release |
| CISO | Can agents cross boundaries or exfiltrate secrets? | Continuous and incident-driven |
| Procurement | Which vendor claim is reproducible? | Every purchase/renewal |
| MSP/MSSP | Which customer workload fits which isolation tier? | Every onboarding/change |
| FinOps lead | What is the cost of an accepted result? | Daily/monthly |

## Packaging hypotheses

| Offer | Price hypothesis |
|---|---:|
| OSS CLI, specification and base adapters | Free |
| Controlled architecture benchmark | $3,000–$8,000 |
| Enterprise/vendor assessment | $12,000–$35,000 |
| Remediation and migration | $15,000–$75,000 |
| Continuous private regression service | $2,000–$10,000/month |
| Managed agent infrastructure | $5,000–$25,000/month |

Prices are hypotheses, not market validation. Validate through paid design partners before hiring or provisioning persistent fleet capacity.

## Business KPIs

- Visitor-to-benchmark-run conversion
- Successful first run within 15 minutes
- Weekly active benchmark repositories
- External adapter pull requests
- Independently reproduced scorecards
- Assessment-to-remediation conversion
- Managed annual recurring revenue
- Gross margin after compute and expert review
- Median evidence-review time
- Vendor correction turnaround
